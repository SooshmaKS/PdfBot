# AI PDF Chat Application 🤖📄

An AI-powered PDF question-answering application built using **Python, AWS Bedrock, LangChain, and AI Agents**.

## Technologies
- Python
- AWS Bedrock
- LangChain
- AI Agents
- Hugging Face

## Features
- Upload and interact with PDF documents
- Ask questions and get AI-generated answers
- Agent-based PDF Q&A
- Multi-agent workflow support
- LLM-powered document understanding
